## 문제

사용자 dogfooding 직접 quote:

> "크롬 켠다음 naver 들어가기 햇는데 지금 크롬만 키고 끝이다 그담 후속을 대응못함 얘가"

Phase 7.0은 *scaffold only* — additive 필드 + enum + IrreversibleActions keyword 박았지만 *behavior change X*. AppDelegate는 항상 panel 띄움. 사용자가 *연속 task* 시도해도 1 step 후 끝.

## 결정 — 같은 ⌥+Space mode-aware 분기

옵션 A: 새 hotkey (예 ⌥+.) 추가
- ✗ 사용자 학습 비용 (외워야 할 키 +1)
- ✗ "전부" target에 부담

옵션 B ⭐: 같은 ⌥+Space + state 분기
- ✓ 학습 비용 0
- ✓ `coordinator.snapshotState()` 1줄
- ✓ 같은 키가 *escape도* — HUD 떠있고 그 외 state 시 cancel

선택 B.

## 박힌 거

### AnalyzeCoordinator — state machine

```swift
// 새 fields:
private(set) var currentInstruction: String?    // 첫 run 시 저장 → continuation에서 재사용
private(set) var idleDeadline: Date?            // 45s waitingForUserClick

// run(_: isContinuation:) — fresh vs continuation 분기
func run(_ req: AnalyzeRequest, isContinuation: Bool = false) async -> AnalyzeStage {
    if !isContinuation {
        sessionID = UUID().uuidString
        history.removeAll()
        currentInstruction = req.instruction
        Log.dispatcher.info("[session] new — sessionID=\(self.sessionID ?? "?")")
    }
    sessionState = .analyzing(stepIndex: history.count)
    // ... capture + dispatcher + OCR + AX 병렬 (기존)
    
    // state transition:
    if result.taskComplete {
        sessionState = .completed
    } else {
        let summary = result.stepActionSummary ?? "step \(history.count + 1) 진행"
        history.append(StepSummary(stepNumber: history.count + 1, actionTaken: summary))
        let deadline = Date().addingTimeInterval(45)
        sessionState = .waitingForUserClick(stepIndex: history.count - 1, deadlineAt: deadline)
        idleDeadline = deadline
    }
}

// continueSession — no-arg, coordinator state로 req 자가 박음
func continueSession() async -> AnalyzeStage {
    guard let prevInstruction = currentInstruction,
          let prevSessionID = sessionID else {
        sessionState = .idle
        return .failed(.invalidResponse("no_active_session"))
    }
    let req = AnalyzeRequest(
        instruction: prevInstruction,
        triggeredAt: Date(),
        sessionID: prevSessionID,
        previousSteps: history.isEmpty ? nil : history
    )
    return await run(req, isContinuation: true)
}
```

### 2-layer irreversible-action gate

```swift
// LLM result + backend keyword filter OR
let isIrreversible = result.requiresConfirmation
    || IrreversibleActions.isIrreversible(nextAction: result.nextAction, targetText: result.targetText)
if isIrreversible && !result.requiresConfirmation {
    Log.dispatcher.notice("[safety] keyword post-filter → requires_confirmation forced true")
}
let safeResult = AnalysisResult(/* ... */, requiresConfirmation: isIrreversible, /* ... */)
```

→ LLM이 한국어 변형 ("이체하기" / "확정" / "탈퇴") 누락해도 *backend가 강제*. 2-layer safety.

### AppDelegate — hotkey 분기

```swift
private func handleHotkey() {
    Task { @MainActor in
        // continueSession path
        if let coordinator,
           case .waitingForUserClick = await coordinator.snapshotState() {
            if self.hud.isShowing { self.hud.dismiss() }
            self.handleContinuation()
            return
        }
        // HUD 떠있고 그 외 state → dismiss + cancel
        if self.hud.isShowing {
            self.hud.dismiss()
            if let coordinator {
                await coordinator.cancelSession(reason: .userEsc)
            }
            return
        }
        // 새 task path
        self.toggleTriggerPanel()
    }
}
```

### Sentinel `.cancelled → .idle` 복귀

```swift
func cancelSession(reason: CancelReason) {
    let prevID = sessionID
    sessionState = .cancelled(reason: reason)
    sessionID = nil
    currentInstruction = nil
    history.removeAll()
    idleDeadline = nil
    Log.dispatcher.info("[session] cancel — reason=\(...) prevID=\(...)")
    // sentinel: .cancelled → 다음 hotkey 시 자연스럽게 새 task path
    sessionState = .idle
}
```

→ `.cancelled` value는 *log에 박혀있지만* state는 immediate idle. 다음 hotkey가 *panel* 띄움 (새 task path).

## 패턴

- **Scaffold-first + wire-second**: Phase 7.0 (additive 필드 + enum, behavior X) → Phase 7.1 (실제 transition + branching). *revert 비용 작게 유지*하면서 *큰 변화* commit 분리.
- **State machine in actor**: Swift 6 strict concurrency에서 actor가 state machine 박는 거 자연스러움. `snapshotState()` await 강제로 race 차단.
- **Sentinel transition**: `.cancelled` value는 log/event용, state는 immediate idle 복귀 → 다음 hotkey 자연스럽게 새 path.
- **2-layer safety gate**: LLM 응답 + backend keyword OR. LLM이 *언어 변형* 빠뜨려도 backend가 잡음. Korean 한정 trap (이체하기/확정/탈퇴) 명시.
