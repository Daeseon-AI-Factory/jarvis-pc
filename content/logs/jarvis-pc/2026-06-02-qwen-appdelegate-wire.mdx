## Fix — env var toggle

`Sources/ScreenBridge/AppDelegate.swift:18` dispatcher 결정 갱신:

```swift
private let dispatcher: (any LLMDispatcher)? = {
    let useLocal = Env.string("SCREENBRIDGE_USE_LOCAL") == "1"
    let gemini = GeminiDispatcher.fromEnvironment()
    let claude = ClaudeDispatcher.fromEnvironment()

    // Local 우선 모드
    if useLocal {
        let qwen = QwenLocalDispatcher.make()
        let cloudFallback: (any LLMDispatcher)? = claude ?? gemini.map { $0 }
        if let cloud = cloudFallback {
            let cloudName = (claude != nil) ? "claude" : "gemini"
            Log.dispatcher.info("AnalyzeCoordinator ready — Qwen LOCAL primary + \(cloudName) fallback")
            return FallbackDispatcher(primary: qwen, primaryName: "qwen-local", fallback: cloud, fallbackName: cloudName)
        }
        return qwen
    }

    // 기존 cloud-only path
    switch (gemini, claude) { ... }
}()
```

### 미세 issue — Optional<Concrete> ?? Optional<Concrete> = type mismatch

처음 박은 `claude ?? gemini` 컴파일 fail:

```
error: cannot use optional chaining on non-optional value of type 'GeminiDispatcher'
note: arguments to generic parameter 'Wrapped'
      ('GeminiDispatcher' and 'ClaudeDispatcher') are expected to be equal
```

→ `Optional<ClaudeDispatcher> ?? Optional<GeminiDispatcher>` = Swift가 type union 추론 못 함.

해법: 명시적 protocol type:

```swift
let cloudFallback: (any LLMDispatcher)? = claude ?? gemini.map { $0 }
```

`.map { $0 }`로 type erasure → `any LLMDispatcher` 추론.

## 패턴 — Phase 박는 3-step에서 3번째 빠뜨림이 *사용자 진척 인식* 깨뜨림

새 dispatcher / 새 service / 새 LLM 박을 때 박는 3-step:
1. **Skeleton** — struct + throw stub
2. **Wire** — 실 구현
3. **AppDelegate (entry point) 끼움** — 진짜 호출 path

*1+2* 박힌 상태로 commit + push 하면 *기술적*으로는 *Phase 박힘*이지만 *사용자 입장에서는 작동 X*. 박는 흐름 *minimum end-to-end*까지 같은 commit 또는 *바로 다음 commit*에 박는 게 *사용자 진척 인식*과 *코드 박힘* 일치.

→ 이 pattern은 *Engineering Playbook*에 박을 가치 (memory: engineering-playbooks-index 갱신).
