## 문제

사용자 직관 quote:
> "이거... 진짜 보안문제되겠는데 제미나이가 다 볼거아니냐"
> "이거는 출시무리인가.... 로컬 llm을 쓰지 않는이상"

화면 전체 capture → Gemini 외부 서버. 그 안에:
- 옆 Slack 채팅 (회사 NDA, 친구 private)
- 1Password 열려있으면 password vault 노출
- 카카오뱅크 계좌 / 잔액
- 코드 secret (.env, API key)
- 의료/법률/세무 정보
- 누군가의 카톡 메시지

→ **target user (시니어 + 비-AI-native + 기업 + global) 못 씀**. ScreenBridge 차별 (user-in-the-loop + *local-first*) 의 *3번째 layer*가 빠져있음.

## 결정 — 3-tier Hybrid

### v0.2 (오늘~2-4주, ship blocker 풀이)

```
Cloud Gemini default + SensitivityRouter (Layer 0)
  ↓ bundleID deny-list 매칭 시
"이 화면은 인터넷에 안 보내요" alert + 요청 차단 (fail-closed)
  ↓ (v0.3까지 차단)
사용자 보안 우려 즉시 부분 답 + Mac App Store 가능
```

deny-list 박힐 거:
- 비밀번호: 1Password / Bitwarden / KeychainAccess
- 한국 은행: 카카오뱅크 / 국민 / 신한 / 하나 / Toss / 우리
- 신용카드: 신한카드 / BC / 삼성
- Mail compose window (sender app == Mail.app + compose window 식별)
- 옵션: 카카오톡 (논의 — 박을지)

### v0.3 (1-3개월, local 본격)

```
Qwen2.5-VL-3B 4-bit (mlx-swift-lm) dispatcher 추가
- 민감 화면 → local-only
- 일반 화면 → cloud (사용자 setting toggle)
- first-launch download 2GB (App Store binary 비대화 회피)
- M1 8GB: load-on-demand (cold start 2-4s)
- M1 16GB+: resident 옵션
```

`LLMDispatcher` protocol 박혀있어 dispatcher 추가만. Phase 7.2 FallbackDispatcher (Gemini → Claude swap) 박은 pattern 그대로 활용.

### v0.4 (WWDC26 결과 dependent, ~6월 중순)

```
Apple FM vision API 발표:
  → 즉시 FoundationModelDispatcher.swift swap (12-24h)
  → 어머님 fit *완벽*: 0GB disk, 0GB RAM, 2-4s, offline, 무료

발표 안 함:
  → Qwen 유지, ship 진행
  → 다음 분기 (WWDC27 또는 macOS 27 release) 재확인
```

3. **WWDC26 발표 X** → Apple FM 막힘. 완화: 추측 위에 v0.2 일정 짜지 X, Qwen 영구 path.

## 패턴

- **Cloud-first ship + local-first migration**: pragmatic-ship-mode 메모리 일치. 100% local-first ship 기다리면 1-2년 timeline + 빅테크 흡수 윈도우 lose. Router layer만 박힌 cloud ship → enterprise pilot 시작 가능 → local swap은 *protocol 박힌 architecture*가 30분에 박음.
- **Fail-closed routing > 100% local**: 기업 컴플라이언스 측면에서 "deny-list 매치 시 무조건 on-device, fail-closed"가 100% local보다 *감사 가능성*이 더 강함. 명확한 routing rule.
- **vendor roadmap에 의존 X**: Apple FM은 *bonus*로 취급, v0.2 일정 결정에 영향 X. WWDC26 발표 dependent path는 v0.4에 박음.
- **Multi-dispatcher protocol 가치**: Phase 2.3에 박은 `LLMDispatcher` protocol이 v0.2 Claude swap + v0.3 Qwen local + v0.4 Apple FM swap *3 시점*에 활용. 한 번 박은 *추상화 layer*가 *3년+ 가치*.
