왜

AI 시대지만
어머님은 어디 누르나요?

ChatGPT가 알려줘도 화면이 그래도 안 보이면 못 함.

"Vercel에서 환경 변수 추가하라"고 들어도 *어디서* 어디 누르나요? AI는 추상적으로 알려주지만 사용자 화면은 구체적인 픽셀.

ScreenBridge가 두 사이를 *번역*합니다. 화면에 빨강 박스 + 한글 안내. 사용자는 그냥 따라 누름.

차별

빅테크 안 잡는 자리.

Operator / Manus / Claude Computer Use가 *자동 클릭*으로 깨진 자리. 우리는 *사용자가 클릭*합니다.

🙋

안내만, 자동 X

AI가 *대신 클릭* 안 합니다. 박스를 박고 사용자가 누름. 잘못 눌러도 *손해 0*. Manus의 credit drain 같은 사고가 *구조적으로* 불가능.

🔒

100% on-device

v0.3부터 화면 *외부 서버에 안 보냄*. Apple Intelligence 모델 + Qwen2.5-VL local LLM. 카카오뱅크 / 1Password / Slack — 화면이 Mac에서만.

👵

어머님 fit

큰 글씨 + 한국어 친화 + ⌥+Space 한 키. AI agent 명령어 외우기 X. 시니어부터 비-AI-native 사용자까지.

비교

빅테크는 이미 사고 났어요.

cloud + 자동 클릭은 *구조적으로* 위험. Apple만 local-first 모델로 안전. ScreenBridge가 그 자리.
